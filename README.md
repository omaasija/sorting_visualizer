# Sorting Algorithm Visualizer
 Built using HTML, CSS, and JavaScript, this project demonstrates how different sorting algorithms work by providing a visual representation of their execution.

✨ Features<Br>
🔹 5 Sorting Algorithms: Bubble Sort, Insertion Sort, Heap Sort, Merge Sort, and Quick Sort<br> 
🔹 Speed Control: Adjustable animation speed from slow to fast<br> 
🔹 Random Array Generation: Generate new random arrays with a single click<br> 
🔹 Real-time Visualization: Watch algorithms sort step-by-step with color-coded animations<br> 
🔹 Algorithm Comparison: Compare time complexities and performance<br> 
🔹 Responsive Design: Works seamlessly on desktop and mobile devices


🎯 Algorithm Explanations<Br>

🔵 Bubble Sort  
Repeatedly steps through the list, compares adjacent elements and swaps them if they're in the wrong order. The pass through the list is repeated until the list is sorted.<br> 
🟢 Insertion Sort  
Builds the final sorted array one item at a time. It's much less efficient on large lists than more advanced algorithms such as quicksort, heapsort, or merge sort.<br> 
🟡 Heap Sort  
Divides the input list into two parts: a sorted sublist of items which is built up from left to right and a sublist of the remaining unsorted items.<br> 
🟣 Merge Sort
A divide-and-conquer algorithm that divides the unsorted list into n sublists, each containing one element, then repeatedly merges sublists to produce new sorted sublists.   
🔴 Quick Sort 
Picks an element as a pivot and partitions the array around the picked pivot, placing the pivot in its correct position in the sorted array.
